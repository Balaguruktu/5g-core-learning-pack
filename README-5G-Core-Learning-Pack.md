# 5G Core Learning Pack (AMF animated)

Interactive offline HTML for 5G Core with **AMF-centred animated call flows**.

## Open in Chrome

Double-click `5G-Core-Learning-Pack.html` or drag it into Chrome.

## Share

- Send `5G-Core-Learning-Pack.html`, or
- Send `5G-Core-Learning-Pack.zip` if mail blocks `.html`

## What’s new (AMF)

1. **AMF deep dive** — responsibilities, interfaces (N1/N2/N8/N11/N12/N15/N22), RM/CM states, NAS message groups  
2. **AMF animated flows** (orange AMF highlight + moving packet + ladder):
   - Initial Registration (AMF) — 12 steps
   - Service Request (AMF)
   - PDU Session via AMF
   - Deregistration (AMF)
   - Plus full PDU Session and Xn Handover
3. Press **Play animation** (or ← → / Space). Use Slow/Normal/Fast.

## Keyboard

| Key | Action |
|-----|--------|
| 1–7 | Sections |
| ← → | Step flow |
| Space | Play / pause |
